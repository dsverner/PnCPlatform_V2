# Domain-rule procedures — the follow-on pass

SCHEMA-DESIGN describes many rules as "the procedure refuses / checks / writes in the same
transaction". This pass builds the tables, the generated base procedures (`<Table>_Add` etc.)
and a small set of core procedures. Every domain rule below is **not yet built**; each entry
cites its design reference so the next pass can work through the list in order. A rule marked
*partial* has a fixed-in-code stand-in until the definition-driven version exists.
