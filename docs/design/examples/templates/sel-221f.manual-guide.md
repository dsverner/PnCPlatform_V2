## PSVC

> Enable the voltage checking function by selecting a PSVC setting of S, P, or E. Voltage checking is disabled when you select PSVC = N. When PSVC = S, the relay asserts Relay Word bit VSC when VS > 59VHI and VP1 < 27VLO (live sync/dead polarizing) for VCT time. When PSVC = P, the relay asserts Relay Word bit VSC when VP1 > 59VHI and VS < 27VLO (live polarizing/dead sync) for VCT time. When PSVC = E, the relay asserts Relay Word bit VSC when either voltage condition is true for VCT time.
>
> — p. 5-9 (PDF page 133)

> The relay allows PSVC settings of S (for live-sync/dead-pol checking), P (for live-pol/dead-sync checking), E (closing is acceptable if either condition is valid), or N (voltage checking disabled).
>
> — p. 5-12 (PDF page 136)

## 27VLO

> Select 59VHI and 27VLO settings based upon your utility standards. Select standard voltage levels where the line is considered live and dead for reclosing purposes.
>
> — p. 5-9 (PDF page 133)

> For the 27VLO setting, we assume that the line is dead for reclosing purposes if line voltage is below 20% of nominal voltage.
27VLO = 0.20 x 132.8 kV = 26.6 kV
>
> — p. 5-11 (PDF page 135)

> The primary setting range check allows 27VLO, 59VHI, and 25DV voltage settings from 0 - 2,000 kV primary. The 27VLO and 59VHI secondary setting range is from 0 - 80.0 V l-n secondary on the polarizing inputs and 0 - 125 V l-n secondary on the synchronism checking input.
>
> — p. 5-12 (PDF page 136)

## 25DV

> Referring to Figure 5.2, note that 25DV is determined from the known angle, ∅. The 25DV setting is approximated with the equation:
25DV = sin(∅) x 59VHI
The value of ∅ should be the maximum angle across the breaker to allow closing.
>
> — p. 5-10 (PDF page 134)

> For our example, for a maximum angle of 30° and 59VHI equal to 80% of nominal phase-neutral voltage on a 230 kV system:
25DV = sin(30) x (0.8 x 132.8 kv) = 53.12 kv
>
> — p. 5-11 (PDF page 135)

> The primary setting range check allows 27VLO, 59VHI, and 25DV voltage settings from 0 - 2,000 kV primary. … The 25DV element setting range is 0 - 150 V secondary.
>
> — p. 5-12 (PDF page 136)

## 25T

> If the 25T time is relatively short, the breaker close time may become a factor. For example, if 25T is set for 60 cycles and the breaker close time is 10 cycles, it actually takes 70 cycles to parallel the line. If this time is critical, the breaker close time should be taken into account when the 25T time is set so that, in this case, a 25T setting of 50 cycles might be more appropriate.
>
> — p. 5-10 (PDF page 134)

> To set the relay, you must know the maximum angle (∅) between VPOL and VS that is allowed for the breaker to close. The slip frequency should be estimated to set the 25T time delay and the breaker close time should also be known.
>
> — p. 5-10 (PDF page 134)

> The slip frequency is the maximum allowed frequency difference between VP and VS. The formula for slip is as follows:
ΔF = (2 x ∅) / (360 x 25T)
Where 25T is the sync-check time delay from the SEL-221F-2, -3, -4 relay setting.
>
> — p. 5-11 (PDF page 135)

> The 25T setting is selected to allow closing under the synchronism conditions outlined above.
25T = 5 sec = 300 cycles
>
> — p. 5-12 (PDF page 136)
