# Transmission line template — `LINE_Template`

Generated by `tools/template_line.py` (#219). The owner, 2026-09-21: the line impedance moves onto the line asset. These are the
characteristics of every asset of type `Line` (the type's default template); a value is recorded per line through
`asset.SetAssetCharacteristic` on the primary-asset screen, under a work request, and the relay rationale reads them as
`line.R1`, `line.X1`, `line.R0`, `line.X0`, `line.LengthMiles`, `line.ChargingMvaPerMile`.

| # | Key | Name | Type | Unit | Base | What it is |
|---|---|---|---|---|---|---|
| 1 | `R1` | Positive-sequence resistance | Decimal | Ω | Primary | Positive-sequence line resistance, ohms primary, end to end. The legacy rationales write it as the real part of Z1 (A4811.docx: 'Z1=1.685+j6.7524'). |
| 2 | `X1` | Positive-sequence reactance | Decimal | Ω | Primary | Positive-sequence line reactance, ohms primary, end to end (the imaginary part of Z1). |
| 3 | `R0` | Zero-sequence resistance | Decimal | Ω | Primary | Zero-sequence line resistance, ohms primary, end to end (the real part of Z0). |
| 4 | `X0` | Zero-sequence reactance | Decimal | Ω | Primary | Zero-sequence line reactance, ohms primary, end to end (the imaginary part of Z0). |
| 5 | `LengthMiles` | Length | Decimal | mi |  | Line length in miles, terminal to terminal (the legacy rationales: 'LL=8.49 miles'; the SEL-221F's LL setting is the fault locator's line length). |
| 6 | `ChargingMvaPerMile` | Charging (MVA per mile) | Decimal |  |  | Line charging in MVA per mile, used for the supervisory overcurrent pickups (A4811.docx: 'ICharge=0.128 MVA/mile*8.49 miles*4.18 amps/MVA'). Optional. |

The distance relay's own copies (the SEL-221F's R1, X1, R0, X0, LL settings) are written from these by the rationale; a line with no
impedance recorded yet is said so on the record's Rationale tab.
